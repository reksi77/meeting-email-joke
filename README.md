A one-line joke about a meeting that should have been an email: nobody wanted to write the email, so they called a meeting instead — and fourteen people sat in the glass room watching a man read his own draft out loud, pausing after every comma like it might object.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt`.
